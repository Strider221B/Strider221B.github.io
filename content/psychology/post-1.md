# Cognitive Load Theory in Interface Design

Cognitive Load Theory (Sweller, 1988) categorizes mental effort into three distinct forms. Understanding these dimensions allows system designers to build software interfaces that maximize focus and reduce cognitive friction.

---

## 1. The Three Forms of Cognitive Load

1. **Intrinsic Load**: The inherent difficulty of the task itself (e.g., reading source code or analyzing a confusion matrix).
2. **Extraneous Load**: The mental overhead introduced by the interface or delivery format (e.g., hunting through convoluted menus or interpreting confusing icons).
3. **Germane Load**: The effort devoted to processing, constructing schemas, and learning.

---

## 2. Desktop Metaphors and Spatial Memory

The desktop metaphor—windows, docks, title bars, and directories—leverages humans' evolved **spatial memory**:
- Users naturally remember *where* an open window was placed on screen.
- Overlapping windows mimic physical documents on a work desk.
- Familiar visual anchors (dock indicators, window control traffic lights) reduce extraneous cognitive load, letting visitors focus on content.

---

## Conclusion

Every millisecond spent searching for a control button or parsing ambiguous iconography is extraneous load subtracted from creative work. Prioritize clarity and spatial consistency.
